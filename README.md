# نظام التقسيط — واجهة الموقع

الريبو ده فيه **واجهة الموقع بس** (شاشة بتعرض البرنامج). الكود والبيانات نفسها على Google Sheets + Apps Script.

| الصفحة | لمين |
|---|---|
| `index.html` | البرنامج للموظفين والمدير |
| `account.html` | صفحة "حسابي" للعملاء (`account.html?t=...` = الرابط الخاص بكل عميل) |

الإعداد الوحيد: حط رابط الـ Web App (آخره `/exec`) في `config.js`.
